# Web Šedivák Stavby – www.sedivakstavby.cz

Ahoj, web je hotový a připravený k nahrání. Nic se nemusí instalovat ani sestavovat.

## Jak ho nahrát

1. Stáhni tohle repo (zelené tlačítko **Code → Download ZIP**) a rozbal ho.
2. **Obsah složky `web/`** nahraj přes FTP do kořenové složky webu na Wedosu.
   Nezapomeň na skrytý soubor `.htaccess` (přesměrování na https a www).
3. Na Wedosu zapni SSL certifikát pro `sedivakstavby.cz` i `www.sedivakstavby.cz`.

## Pozor na doménu a e-maily

- DNS domény teď vedou na **Wix** (tam běží starý web), pošta je na **Wedosu**.
- Při přepnutí DNS na Wedos zachovej **MX záznamy**, jinak přestane chodit pošta na @sedivakstavby.cz.
- Wix zrušit až ve chvíli, kdy nový web i pošta fungují.

## Formulář

Kontaktní formulář už funguje přes EmailJS (účet Šedivák Stavby s.r.o.), nic se nenastavuje.
